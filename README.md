# 推しメモ帳

Vtuber のファンマーク・ファンアートタグ・色・参考画像をまとめて保存できるメモ帳アプリです。
データは **使っている人の端末（ブラウザ）の中だけ** に保存されます。登録やログインは不要です。

## できること

- 名前・事務所・ファンマーク・ファンアートタグなどを登録して、**押すだけでコピー**（項目は自由に追加・削除・名前変更）
- 髪の色・目の色などの **色の登録**（カラーコードをコピー可）
- **参考画像** を Vtuber ごと・フォルダごと（例: 通常衣装）に保存
- 拡大表示で **左右反転・白黒・ズーム・スポイト**（拾った色をそのまま登録）
- 画像に **ひとことメモ**
- ファンアートタグ入りで **X の投稿画面を開く**（文章はテンプレートで変更可）
- **誕生日**（1 か月前からカウントダウン）、**お気に入り**、**リンク**（複数）、**アイコン**
- 名前・ふりがなで検索、あいうえお順の並び替え
- **バックアップ**（画像込みの .zip / 文字だけの .json）と読み込み

## ⚠ 使う前に知っておいてほしいこと（注意点）

1. **データはこの端末のこのブラウザの中だけに保存されます。**
   サーバーには何も送られないので、作者を含めてほかの人に見られることはありません。
2. **PC とスマホなど、別の端末とはデータが共有されません。**
   お引っ越ししたいときは「⚙ 設定 → 画像も含めて書き出す（.zip）」で作ったファイルを、別の端末で「読み込む」してください。
3. **ブラウザの「閲覧データ（履歴・Cookie・サイトデータ）の削除」をすると、データも消えます。**
   シークレットモード（プライベートブラウズ）では、閉じると消えます。
4. **iPhone・iPad（Safari）では、7 日間サイトを開かないとデータが消えることがあります。**
   Safari の共有ボタン →「ホーム画面に追加」して、ホーム画面のアイコンから開くと消えにくくなります。
5. **ときどきバックアップしてください。**
   端末の故障・紛失・機種変更に備えて、書き出したファイルを PC やクラウドに保存しておくと安心です。
   最後のバックアップから 30 日たつと、アプリの上にお知らせが出ます。
6. **画像をたくさん保存すると、端末の容量を使います。**
   画像は元の画質のまま保存されます。使っている容量は「⚙ 設定 → 保存について」で確認できます。
7. このアプリの不具合などでデータが失われても、作者は責任を負えません。大事なデータはバックアップしてください。
